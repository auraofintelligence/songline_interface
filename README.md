# The Songline Interface - conceptual proposal

> **Status: conceptual interface proposal.** It does not claim Traditional Owner authority, cultural approval, or permission to identify, represent or disclose restricted knowledge.

The Songline Interface is a static design proposal that experiments with a layered interface for relating place, memory and project ideas. Its language and interactions are speculative design material, not cultural records, protocols or an authorised knowledge system.

Visit the [public proposal](https://auraofintelligence.github.io/songline_interface/) or inspect the [GitHub repository](https://github.com/auraofintelligence/songline_interface).

## What is here

The main page explores a "Lattice of Resonance" through visual layers, tags and an abstract constellation. The separate laboratory page contains interaction sketches such as narrative, exchange, consent and node-status demonstrations. These are interface concepts, not operating community infrastructure or cultural data.
